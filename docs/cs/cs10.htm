Instructions

  • Complete the programming tasks below by the due dates announced in class.
  • Use VS Code to create, edit, and test your programs. Be sure each program does what it is required to do!
  • You must do all of the coding in class without using a coding agent or copying code from the internet; the code you write must be entirely your own!
  • Create the files in the cs10/python or cs10/web folder of your Computing Science OneDrive folder, as appropriate...
    1. In VS Code, open your cs10 folder.
    2. Right-click on the folder where you want to create the new file. Use your python folder for the Structured Programming projects and your web folder for the Client-Side Scripting projects.
    3. Select New File...
    4. Type the file name as given in the project instructions.
  • All programs should have a docstring and relevant comments.
  • Use the “IPO” (Input, Processing, Output) program structure.
  • Use descriptive names for variables.
  • Use only programming techniques that have been covered in these lessons. Examples that you find on the web often use techniques that are considered bad programmming practice that should be avoided.
