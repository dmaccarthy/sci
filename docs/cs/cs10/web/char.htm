Formatting Tags

Sometimes you may want to emphasize some of the words in your text. HTML provides tags to accomplish this. The code below produces a paragraph of text all in the default style.

<p>My favourite 80’s movie is Raiders of the Lost Ark.</p>

Suppose you want to emphasize the word "favourite" and the movie title. To do this, you could change your code to:

<p>My <strong>favourite</strong> 80’s movie is <em>Raiders of the Lost Ark</em>.</p>

The <strong> and <em> tags split the paragraph text into several different nodes. The <em> tag is short for emphasis. Most browsers will display this text in italics by default. The <strong> tag usually causes text to be displayed in bold.

We will learn in a future lesson how to customize the style in which each element’s text is displayed.

Anchors & Hyperlinks

Another useful HTML tag is the anchor tag, abbreviated as the letter <a>. An anchor is a portion of your document that links to another document on the web. You can mark off text as an anchor exactly as you mark off text to be emphasized.

<p>Please visit the <a>Sal Comp website</a>.</p>

To make the anchor actually work, you need to specify the web address (uniform resource locator or URL) of the document being linked. You do this by giving the anchor element an href (hypertext reference) attribute.

<p>Please visit the <a href="https://www.salcomp.ca">Sal Comp website</a>.</p>

There are two ways to specify a URL. The example above is an absolute URL; it begins with https:// or another protocol that your browser supports. This method is usually used to link to documents located on a different server than the document that contains the anchor.

When linking to a document located on the same server (e.g. a different page within the same website), a relative URL is usually used instead. Relative URLs do not include https:// or any other web protocol. Instead, the web browser assumes that the URL is relative to the folder containing the current page.

href...Means
someFile.htmlA document in the same folder as the current document.
someFolder/someFile.htmlA document in a subfolder of the one containing the current document.
../someFile.htmlA document in the parent folder of the one containing the current document.

Titles

All of the tags we have introduced so far for the body of the HTML document (except for the line break tag) support a title attribute. This attribute is used to display additional information when the mouse is positioned over the text.

<p title="Good job!">Place your mouse here.</p>

Sometimes, you may want to attach a title to a specific word or words (not the whole paragraph) without changing the style in which the text is displayed. There is a tag called <span> that can be used to mark off text without changing its appearance:

<p>I go to <span title="Great School!">Sal Comp</span>.</p>
